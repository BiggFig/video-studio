# Tally: document to published form

This is a manually authored, source-grounded 18-second HTML/SVG film. It is not an automatically generated campaign, a capture of operating Tally, or evidence of a real submitted response. Old films and source artifacts remain unchanged.

The main idea is physical continuity: a typed document gains question blocks, becomes a finished form, then passes from its creator to a respondent. The UI supplies the motion. There are no decorative crowds, confetti, tickers, saturated editorial backgrounds or unrelated floating objects.

The public GIF is retained under `.local/tally-motion-sources/create-form.gif`; sampled evidence is beside it.
- [Keyboard shortcuts](https://tally.so/help/keyboard-shortcuts): `/` opens the block menu; `/email` and `/multiple` select the demonstrated block families. Question entries create labels and inputs together.
- [Input blocks](https://tally.so/help/input-blocks): email and multiple choice are real supported input types. The shortened two-question film form is authored from these blocks.
- [Default thank-you page](https://tally.so/help/how-to-create-a-thank-you-page): supplies the actual completion message and its relationship to submission. The unchanged full screenshot and hash are in `.local/launch-tally-sourcepack-20261003/provenance.json`.
- [Press kit](https://tally.so/help/press-kit): establishes the form-builder category and creator audience. The official Tally icon SVG path was inspected directly in the help-center header. Bundled Geist substitutes for the original interface font; the adjacent Tally word is typeset, not presented as exact logo artwork.
