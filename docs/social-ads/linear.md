# Linear: keep the context

This is an original, manually art-directed engine study for a product-team audience. It is an unofficial illustrative demonstration, not a paid campaign, an authenticated product capture, or proof of advertising performance.

## Hypothesis

“Still copying bugs into an AI chat?” should qualify a more specific audience than “Bug reported. Now what?” The film then answers that friction with a visible action (select Linear as the issue's agent), an observable result (a linked draft PR), and a consequence (the person reviews proposed work while the issue context stays connected). The hypothesis needs a campaign experiment; it is not a promise of conversion improvement.

## Placement designs

- **Reels: 1080 × 1920, 18 seconds, 30 fps.** Essential copy and action remain inside x80–1000 and y290–1230; only unlabelled panel contours and a faint grid extend outside. The actual film composition is vertical rather than a cropped desktop screen.
- **Feed: 1080 × 1350, 18 seconds, 30 fps.** Separately authored placement coordinates, taller issue/draft panels, more breathing room between issue properties, expanded consequence rows, and an upper brand lockup. It is not a uniform crop/scale of Reels.
- Main headlines are 83–106 px, essential issue and action labels 38–76 px before transforms. The silent story contains its own hook, selection, result, consequence, and CTA.
- Monochrome near-black, Mercury White and Nordic Gray preserve Linear's documented visual palette. Editorial logo geometry approximates the brand in monochrome and is not official supplied artwork.

## Suggested primary copy

**Paid:** Still copying a bug report into another AI chat? Delegate from the issue in Linear, keep the context attached, and review the draft PR yourself. Explore Linear Agent. Coding sessions require workspace setup and repository access and use AI credits.

**Organic:** The issue already contains the context. Start there. This short walkthrough shows a Linear Agent coding session moving from an issue to a draft PR—with a person still responsible for reviewing the work. How does your team handle the handoff today?

Suggested destination: https://linear.app/docs/coding-sessions . Suggested native ad CTA: **Learn more**. No campaign has been launched or audience selected.

## Product evidence and boundaries

Verified 2026-10-05 against official sources:

- [Linear Agent](https://linear.app/docs/linear-agent): Linear's built-in agent can be delegated implementation work.
- [Assign and delegate issues](https://linear.app/docs/assigning-issues): the human assignee remains responsible when an agent is delegated an issue. Agent membership and workspace setup govern access.
- [Coding sessions](https://linear.app/docs/coding-sessions): coding sessions start from issue context, use configured repositories, and can produce a draft PR for a person to inspect. Current availability is Basic, Business and Enterprise, with setup and AI credits. The archived-search issue is adapted from the page's “Writing effective issues” example.
- [Brand guidelines](https://linear.app/brand): monochrome wordmark usage is preferred; Mercury White is #F4F5F8 and Nordic Gray is #222326.

The current official assignment and coding-session images were visually inspected. The video enlarges and repositions their recognizable issue/assignee/agent/draft concepts for a phone screen; it does not purport to reproduce exact native mobile layout, a real live coding session, or its duration. No code diff or successful test result is fabricated. No merge, completed state, numerical speedup, customer quote, conversion claim, or free-plan availability is shown.

Creative mechanisms drawn from the researched portfolio: ClickUp's immediate workplace-friction question; monday.com's visible input-to-output chain; Figma's persistence of the same meaningful object across visual transformations. None of their copy, performance claims, artwork or palettes is reproduced.

Evaluation should compare the original hook against this version with placement, audience, destination and spend held consistent; use qualified activations as the outcome and early retention only as a diagnostic. Organic engagement and paid acquisition are separate tests. Soundtrack reuse isolates the visual/story change and does not establish music licensing clearance for an advertiser's campaign.
