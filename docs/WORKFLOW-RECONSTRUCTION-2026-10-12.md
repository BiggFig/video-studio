# URL workflow reconstruction — 12 October 2026

Continuation of the director checklist after the first OpenRouter tests. This batch improves the evidence entering research and the contract between research and HTML UI reconstruction. The six authored Tally exports remain the approved pilot, not automatic URL passes.

## Changes

- Research selects one explicit observed start, one to three supported actions, and an observed or illustrative result surface before scripting. Source IDs, capability facts and supplied DOM control IDs are checked. Fresh launch jobs require this declaration; retained older research remains readable.
- UI generation can refuse with an empty document map when source evidence is insufficient. A successful response still needs every selected target, faithful source text, valid geometry, actual controls and a substantive result. Code samples cannot become input controls; graph edges must connect real nodes.
- Source sampling spans semantic and spatial regions instead of filling its allowance with the first nested code spans. Visible preview text and later controls survive; hidden fields and sensitive form values remain excluded.
- Public user documentation and observed task guides are eligible within the existing two-page research allowance. Readable server-rendered guides do not wait indefinitely for deferred third-party scripts. Each guide records the actual page that linked to it.
- Recognized PNG, JPEG and WebP bytes can be decoded when their server supplies generic binary MIME. Explicit conflicting formats remain rejected; download, codec, image and dimension checks still apply.
- Explicit speculative prefetches are excluded and selected documents receive priority over queued optional resources. The four active download slots and shared transfer limits are unchanged.
- Marketing, pricing and page-sizing CSS hints are distinguished from actual interface panels so they do not consume the focused source inventory.

No automatic job receives additional model calls, output tokens, audio generations, repair attempts or wall time from these changes. A research description can contain up to 240 characters so complete starting-state qualifiers survive; it is not truncated or promoted to source evidence.
