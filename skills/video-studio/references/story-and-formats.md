# Story and format recipes

Start with viewer, one message, intended outcome, available evidence. Default choices fill missing details without a long interview. A finished-video request authorizes planning and rendering; genuinely missing essentials go to needs_input.

## Product URL / PRD / screenshots

Capture actual UI and brand assets. Distinguish shipped features from planned PRD items. Record supported claims. Select a central flow: entry → meaningful action → visible result. Show the actual product delivering it. Use real screenshots for controlled staging, recordings when the interaction proves the claim.

A starting 15–25 second arc is hook → reveal → 2–3 demonstrated benefits → outcome/CTA. Adapt duration to message. Make the product recognizable early. Never invent testimonials, metrics, urgency, discounts, capabilities, or interfaces.

Storyboard exact duration, purpose, source, text, composition, attention target, entry/hold/exit, transition, sound. “Cinematic” is not a scene spec. Specify which UI region fills the frame, where the cursor lands, and what changes. About 0.3 seconds per word after settling is an initial readability estimate; test actual output.

| Format | Construction | Verification |
|---|---|---|
| UGC/talking head | Complete thought, best take, relevant B-roll, precise captions | Meaning, crop, sync |
| Demo | Setup → action → result; actual UI, deliberate cursor, focal zoom | Actual controls/results |
| Launch/teaser | Hook → reveal → feature montage → outcome | Brand/reveal timing |
| Performance ad | One promise, supported evidence, one CTA | Message matches destination |
| Testimonial | Supplied verbatim quote, exact author/rating | Attribution/text |
| Offer/sale | Product, accurate offer, terms/code, CTA | Price and real deadlines |
| Explainer | Question → mechanism → example → takeaway | One idea per beat |
| Deck | Rebuild slides, narration determines holds | Values/build order |
| Photo slideshow | Subject-aware fit, varied restrained pan/zoom | Faces/framing |
| Podcast/audiogram | Speech-first highlights, actual waveform, captions | Quote/timing |
| Text story | Source-backed or clearly fictional bubbles | Reading time/attribution |
| Wrapped/recap | Meaningful stat/highlight progression | Units/exact values |
| PR/release | Real diff → behavior consequence → before/after | Grounded change |

Multi-aspect exports recompute crop/layout/safe areas, not blind resizing. Variants use one template, explicit row data, stable IDs, exact copy, and one controlled change for a hypothesis. Inspect real variant props before batch rendering. Recipes do not guarantee virality/conversion.

For voiced creation write natural supported speech, generate audio, measure duration/timing, then set holds. If speech cannot fit, revise script or extend permitted duration. Do not truncate sentences or rush a voice to satisfy an arbitrary timer.
