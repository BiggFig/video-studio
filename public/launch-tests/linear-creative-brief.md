# Linear: keep the context

An original 18-second creative study for product teams, with separate 9:16 Reels/Stories and 4:5 feed compositions. It is an unofficial illustrative demonstration. No advertising campaign has run and no performance lift is claimed.

## Creative hypothesis

“Still copying bugs into an AI chat?” names a specific handoff frustration. The opening also promises **Issue → draft PR**. The film then shows a deliberate agent-selection action, a linked draft result, and a person retaining responsibility for reviewing the proposed work. This should be tested against the previous opening using qualified product activations, with early retention used to diagnose attention.

## Publishing copy

**Paid primary text:** Still copying a bug report into another AI chat? Delegate from the issue in Linear, keep the context attached, and review the draft PR yourself. Explore Linear Agent. Coding sessions require workspace setup and repository access and use AI credits.

**Paid headline:** Keep the context. Review the draft.

**Native CTA:** Learn more.

**Suggested destination:** https://linear.app/docs/coding-sessions

**Organic caption:** The issue already contains the context. Start there. This short walkthrough shows a Linear Agent coding session moving from an issue to a draft PR—with a person still responsible for reviewing the work. How does your team handle the handoff today?

## Design and product fidelity

The Reels/Stories composition is 1080 × 1920; the feed composition is independently arranged at 1080 × 1350. Both are 18 seconds at 30 fps. The film uses phone-legible interface fragments, persistent issue identity, a deliberate selection, one dramatic light/dark change, and readable result holds. Key messages and controls occupy conservative placement-safe regions. The music is retained from the preceding study so the visual change can be assessed with sound off.

The UI is an editorial reconstruction of documented product behavior, not an exact native mobile recording. Large typography, camera movement, condensed panels and menu position are creative staging. The draft result never changes into a merge, completed issue, verified test, or quantified time-saving claim. No invented code diff is shown. The monochrome palette follows Linear's Mercury White and Nordic Gray guidelines.
