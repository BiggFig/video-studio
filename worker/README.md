# Isolated production worker

Run `npx tsx worker/index.ts --input /job/input.json --workspace /job`. Node 24.x, FFmpeg/FFprobe, Python 3, Poppler `pdftotext`, and Playwright Chromium are required. Python runs in explicit UTF-8 mode for portable plan validation. The web orchestrator supplies approved provider secrets to the isolated process, never the input file. Set `ANTHROPIC_API_KEY` (or `AI_GATEWAY_API_KEY`/`VERCEL_OIDC_TOKEN`), `ELEVENLABS_API_KEY`, `WORKER_CALLBACK_URL` (the job checkpoint URL), and the scoped `PIPELINE_CALLBACK_TOKEN`. `ANTHROPIC_MODEL`, `AI_GATEWAY_MODEL`, `ELEVENLABS_MUSIC_MODEL`, `PYTHON_PATH`, `FFMPEG_PATH`, `FFPROBE_PATH` and `VIDEO_STUDIO_SKILL_PATH` are optional runtime settings.

`WorkerInput` in `types.ts` is the server-to-worker contract. Private input/resume URLs are fetched with the callback bearer token only when their origin exactly matches the callback origin. Arbitrary destinations and every browser resource are DNS-validated, connection-pinned, redirect-validated and byte-limited. Reference links must directly return a video file. Social-page downloads and authentication bypasses are unsupported and produce an actionable input error.

The worker checkpoints artifacts to private object storage before recording completion. `POST artifact` with `{operation:"prepare",path,size,contentType,sha256}` returns `{clientToken,pathname,grant}`; the worker uploads directly to Blob with the scoped token, then commits `{operation:"complete",path,url,grant}`. `POST checkpoint` persists `{status,checkpoint}`, `{status:"ready",result}`, or `{status,error}`. Large videos never pass through a web function's request body.

Paid audio generation is reserved durably before the external request. Bytes are durably uploaded before that reservation is marked completed. Retries reuse a valid hashed output. An interrupted reservation fails closed with `audio_payment_uncertain` instead of billing twice; an operator must recover the external result or explicitly resolve the reservation. Model/audio/ASR usage and provider request IDs are recorded. Actual monetary cost is nullable until billing reconciliation, never fabricated from unverified estimates.

Direct Anthropic requests first use the free token-count endpoint with the same model, system message and complete input. The count is an estimate: the worker reserves 15% plus 1,024 tokens above it, records request hashes and the reservation before generation, and reconciles actual usage afterward. Gateway requests or an unavailable/invalid counter retain the conservative byte/pixel estimate. A usage overrun or unresolved prior model reservation stops further automatic provider calls; budgets are never enlarged to make a review pass. See [Anthropic's token-counting documentation](https://platform.claude.com/docs/en/build-with-claude/token-counting).

The pinned unified skill owns the workflow. The runtime hashes its loaded chapters and refuses to resume under a changed skill/runtime. Every plan has frame-exact contiguous scenes and supporting literal source quotes. The compositor uses actual media, local escaped HTML typography, deterministic FFmpeg entrances, full-HD H.264/AAC, instrumental music and selective SFX. Speech-bearing product recordings are used whole or rejected; music is ducked below them. No TTS or generated voiceover endpoint exists.

URL capture keeps page screenshots for context and may additionally retrieve complete, publicly linked product raster images. The extractor filters logos, portraits and unsuitable dimensions, records original-image hashes/provenance, and uses the same 55 MB capture budget. It accepts at most four originals in six attempts, with a 24 MB local byte allowance and a 20-second scheduling cutoff; in-flight requests retain the existing inactivity timeout and whole-worker ceiling. These are public-page images, never represented as authenticated application captures. Analysis uses smaller previews while rendering retains the complete normalized source.

Delivery requires full-file decode and metadata validation, timeline/source bounds, DOM layout inspection, Claude review of actual decoded scene/hold/seam frames, source-grounded claims, reference-source exclusion, actual loudness/true-peak measurement, and final Scribe speech/audio-event analysis. The QC record describes performed checks and explicitly does not claim human listening. Up to two targeted repairs are allowed. Failure remains `needs_review`; no fallback/demo output is published. Internal sources, scene HTML, composition, plan, storyboard, draft, usage, reviews, final and poster are retained by the host's retention policy.

Repairs reserve their allowance in `analysis/repair-ledger.json` before any paid repair call. Retries restore the consumed count and verify the last applied plan hash; an unresolved reservation fails closed for operator review. The worker also honors dispatch's absolute `deadlineAt`, using the smaller remaining job time or attempt allowance. Retries cannot reset either repair or total execution limits. Non-rendered summary/purpose/reference-technique notes are bounded deterministically while raw provider responses remain retained; visible copy, source grounding and timeline validation are unchanged.

Validation commands: `npm test`, `npm run typecheck`. A real paid end-to-end acceptance run requires configured providers and the durable artifact service. Unit tests alone do not certify generated video quality.

`node --env-file=.env.local --import tsx scripts/acceptance-local.ts --run-paid --url https://example.com --workspace .local/acceptance-example` exercises the exported pipeline locally with actual providers and verified filesystem checkpoints. `--fixture .local/acceptance-fixtures/submission-fixture.json` can replace `--url` for an explicitly authorized PRD/reference acceptance. The fixture adapter verifies exact manifest hashes, sizes and confined paths; only this local runner supplies its programmatic input-reader dependency. The production CLI and API always use the normal public-network and authenticated-upload reader. Local success does not prove production uploads, queue execution, private storage or owner access. The operator must have authorization for the supplied source material to be analyzed by the configured external providers. `--run-paid` is a deliberate execution flag, not a substitute for that authorization.

The local runner preserves raw responses and aggregate provider usage across explicit recovery. Saved-review recovery uses actual retained findings to request a repair and performs fresh complete QC afterward; it never promotes an earlier partial review to a passed check. Once a retained-review repair is reserved, further resume of that recovery folder is prohibited so its consumed repair allowance cannot reset. Claude visual review compares actual output frames with original source previews, and reference acceptance requires both a performed comparison and an explicit successful style-adoption assessment.

`npx tsx worker/smoke-render.ts --out .worker-smoke` tests the actual renderer with an explicitly synthetic fixture and generated sine-wave audio, including full-file decode in all three formats. This fixture can never invoke the delivery callback. `worker/smoke-sandbox.ts` performs that same check in the configured Vercel snapshot and retrieves the MP4s for inspection; it requires authorization to upload the source to that environment. As of implementation, local Windows smoke outputs passed in all three ratios; Linux/provider-backed end-to-end validation remains separate.
